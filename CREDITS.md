## Sprite license check (PMD Collab SpriteCollab)

We checked the PMD Collab SpriteCollab repository (sprites.pmdcollab.org / GitHub `PMDCollab/SpriteCollab`) as a possible bundled source:

* The project's submission policy licenses community submissions as **CC BY-NC 4.0**. The GitHub repo has no LICENSE file (GitHub reports "Other / NOASSERTION").
* Its `tracker.json` credits the base sprite **and** portrait of every species #1–251 to **CHUNSOFT**, meaning they are official *Pokémon Mystery Dungeon* game assets, not community art. The only non-Chunsoft credits are shiny recolours derived from those assets.

That art is outside the CC BY-NC grant and would break this project's "no official art" rule, so **it is not included**.

Pokémon is a trademark of Nintendo / Creatures Inc. / GAME FREAK inc. This is a non-commercial fan project with no affiliation.
